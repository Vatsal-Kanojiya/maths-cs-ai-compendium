# Per-chapter handoff notes

Chapters 15–18 were built by parallel runs. To keep those runs from colliding on the shared
files, each run writes its state row, README entry and "lesson worth generalising" here, in
`chNN.md` (or `ch16-partN.md`), and the coordinating run folds them into `../README.md` and
`../HANDOFF.md`. Once folded, a note stays here as the run's own record.
